# 📚 Painel de Estudos

Uma aplicação web simples e organizada para leitura e consulta de tópicos de estudo, códigos e conceitos.

## 🎨 Paleta de Cores
- **Rosa Pastel:** `#F8DAE2`
- **Magenta Suave:** `#B3395B`
- **Bege Retrô:** `#F7F3E9`
- **Pink Destaque:** `#FF2A75`

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura principal da página.
- `style.css`: Estilização dos filtros, fontes e cartões.
- `script.js`: Lógica de renderização dos cartões, busca e filtros.
- `README.md`: Instruções de utilização e documentação.

## ⚡ Funcionalidades
- **Filtros por Categoria:** Navegue rapidamente entre assuntos (ex: JavaScript, CSS, Conceitos).
- **Busca Interativa:** Pesquisa rápida por palavra-chave ou tag.
- **Ajuste de Fonte:** Botões para aumentar ou diminuir a fonte do conteúdo dos cartões conforme preferir.
