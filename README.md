# trabalho_feke_news
# 📚 Painel de Estudo & Cópia Rápida

Uma aplicação web desenvolvida para facilitar a visualização, estudo e cópia rápida de fragmentos de código, comandos e resumos.

## 🎨 Paleta de Cores
- **Rosa Pastel:** `#F8DAE2`
- **Magenta Suave:** `#B3395B`
- **Bege Retrô:** `#F7F3E9`
- **Pink Destaque:** `#FF2A75`

## 📁 Estrutura de Arquivos
- `index.html`: Estrutura HTML da aplicação.
- `style.css`: Estilos customizados, scrollbars e regras para ajuste de fonte.
- `script.js`: Lógica de renderização dinâmica, filtros, busca, cópia e suporte a *Toasts*.
- `README.md`: Instruções de utilização e documentação.

## 🚀 Como Executar
1. Baixe todos os arquivos na mesma pasta.
2. Abra o arquivo `index.html` em qualquer navegador moderno.

## ⚡ Funcionalidades
- **Cópia em 1 clique:** Clique em qualquer bloco de código para copiar seu conteúdo direto para a área de transferência.
- **Busca em Tempo Real:** Pesquise por título, palavras-chave ou tags.
- **Filtros por Categoria:** Organize por assuntos como JavaScript, CSS, Atalhos, etc.
- **Cópia em Lote:** Botão para copiar todos os blocos visíveis de uma única vez.
- **Ajuste do Tamanho do Texto:** Controles para aumentar ou diminuir a fonte do conteúdo visualizado.
